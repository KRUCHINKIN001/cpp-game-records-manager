# Менеджер игровых рекордов (C++)

Консольная программа для хранения, просмотра и поиска игровых рекордов. Данные сохраняются в бинарном файле `records.dat`.

## Функционал

1. **Добавление рекорда:** Запрашивает имя (до 19 символов), количество очков и уровень. Данные записываются в конец файла.
2. **Просмотр рекордов:** Построчно читает бинарный файл и выводит все сохраненные записи.
3. **Поиск по имени:** Запрашивает имя и ищет все совпадения в файле.
4. **Очистка:** Полностью удаляет все записи (обнуляет файл).

## Как работает бинарный файл

Программа использует структуру `Record`:
```cpp
struct Record {
    char name[20];
    int score;
    int level;
};
